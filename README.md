# Dhiraj Shah — Engineering Intelligent Systems

Personal portfolio website of **Dhiraj Shah**, 4th-year Computer Engineering undergraduate at Tribhuvan University — Institute of Engineering (TU IOE), Nepal.

🌐 **Live Website**: [https://dhiraj-7x7x.github.io](https://dhiraj-7x7x.github.io)

---

## 🚀 Key Highlights & Interactive Features

- **SAARC Legal RAG Architecture Simulator ("RAG Lab")**:
  - Interactive workbench simulating a 6-stage multimodal legal retrieval pipeline across Nepal, Bhutan, and Bangladesh statutory corpora.
  - Features real-time toggling for speech recognition (Whisper Large-v3 Turbo), cross-lingual translation (IndicTrans2 / NLLB-200), hybrid retrieval (BM25 + BGE-M3 + Cross-Encoder), and speech synthesis (Coqui XTTS-v2).
- **Engineering Capability Radar**:
  - Interactive 4-axis SVG radar chart visualizing systems engineering, AI/neural retrieval, software architecture, and signal processing proficiencies against 2026 industry targets.
- **TU IOE Syllabus Mapping**:
  - Interactive explorer detailing how core coursework (Embedded Systems, DSP, Distributed Systems, Networks, Theory of Computation) bridges directly into applied AI/ML engineering.
- **Live Profile Studio & Customizer**:
  - Slide-over drawer enabling instant real-time customization of profile credentials, institutions, and themes, with 1-click standalone HTML export.
- **4 Curated Aesthetic Themes**:
  - *Midnight Library* (Obsidian Slate & Luminous Gold — Default)
  - *Midnight Cyber* (Deep Carbon, Cyan & Emerald)
  - *Warm Parchment* (Cream Paper & Terracotta Ink)
  - *Botanical Sage* (Deep Pine, Sage & Warm Brass)
